FCEA3LAB 1.1
============================================================================

NASA CEA v3（Chemical Equilibrium with Applications, 2026 年の近代化版）を
FCEA2 と同じ感覚で使えるようにした実行ファイルです。Windows・mac・Linux で
動きます。

  * NASA の公式配布物ではありません。NASA CEA v3.3.4（github.com/nasa/cea,
    コミット 2f79a64）に手元の修正 4 件を当ててビルドした非公式版です。
  * 計算結果は FCEA2 と出力桁の範囲で一致することを確認済みです（下記）。

  1.0 からの変更（1.1）
  * mac / Linux でダブルクリックして起動したとき、.inp が見つからなかった問題を
    修正（作業フォルダに無ければ FCEA3LAB と同じフォルダ・その samples も探す）。
  * ファイル名を聞かれたときに .inp をドラッグ＆ドロップで指定できるようにした。
  * 見つからないときに探した場所を表示し、起動時に出力ファイルの場所を表示する。
  * mac で起動を止められたときの手順を最新の macOS に合わせて更新（下記 5.）。
  計算結果は 1.0 と同じ。1.0 を使っている人は入れ替えるだけでよい。


1. 使い方（FCEA2 と同じ）
----------------------------------------------------------------------------
  (1) 作業フォルダに入力ファイル（例: mycase.inp）を置く。
  (2) そのフォルダで FCEA3LAB を起動し、拡張子なしのファイル名を入力する。

        > cd 作業フォルダ
        > C:\tools\FCEA3LAB\FCEA3LAB.exe
         ENTER INPUT FILE NAME WITHOUT .inp EXTENSION.
        mycase

      引数で渡しても、パイプで渡してもよい:
        > FCEA3LAB.exe mycase
        > echo mycase | FCEA3LAB.exe

  (3) mycase.out が同じフォルダにできる。

  ダブルクリックで起動した場合:
  * Windows は FCEA3LAB.exe のあるフォルダ、mac / Linux はホームフォルダが
    作業フォルダになる。
  * ファイル名を聞かれたら、.inp ファイルをウィンドウにドラッグ＆ドロップすれば
    フルパスが入る（そのまま Enter）。.out は .inp と同じフォルダにできる。
  * 名前だけ入力した場合は、作業フォルダ → FCEA3LAB と同じフォルダ → その samples\
    の順に探す。
    見つからないときは、探した場所が表示される。

  * thermo.lib / trans.lib を作業フォルダに複写する必要はありません。
    FCEA3LAB.exe と同じフォルダにあるものを自動で使います。
  * 起動時に、どのデータベースを使ったかが表示されます。.out の先頭にも書かれます。
  * フォルダ名に日本語や空白が入っていても動きます。


2. データベースを探す順番
----------------------------------------------------------------------------
  1. 作業フォルダ（カレント）の thermo.lib / trans.lib
  2. 環境変数 CEA_DATA_DIR が指すフォルダ
  3. FCEA3LAB.exe と同じフォルダ（同梱の新しいデータベース）
  4. FCEA3LAB.exe と同じフォルダの data\

  作業フォルダに FCEA2 用の古い thermo.lib を置いたままだと、そちらが使われます
  （形式は互換なので計算は正しく動きますが、v3 での修正・追加は入りません）。
  起動時の表示で確認してください。

  自前のデータベースを作るとき:
    > FCEA3LAB.exe --compile-thermo thermo.inp
    > FCEA3LAB.exe --compile-trans trans.inp
  作業フォルダに thermo.lib / trans.lib ができ、以後そのフォルダでは優先されます。
  元データは data_src\ にあります。


3. FCEA2 との違い（必ず読むこと）
----------------------------------------------------------------------------
  (a) .out の書式が違う。数値は同じだが、行ラベルが変わっている
      （例: "CSTAR, M/SEC" → "C*, m/s"、"GAMMAs" → "Gamma_s"、
       密度は "0.3083E+1" 表記、列があふれた継続ページに見出しを再掲しない）。
      FCEA2 の .out を読む自作スクリプトは、そのままでは読めないことがある。
  (b) .plt は FCEA2 と同じ形式で出力する（NASA の v3 では未実装だったものを
      FCEA3LAB で追加）。"output" の後に "plot p t isp ..." と書く。変数名の
      規則・書式・行の並びは FCEA2 と同じで、FCEA2 と照合済み。違いは次の 2 点:
        - FCEA2 が内部事情で 0 を書いていた列（気体だけのときの m / mw の片方、
          凍結流だけを解いたときの isp 等と化学種）には実際の値を書く。
        - 衝撃波問題（shock）は .plt に行を出さない。
      平衡と凍結を両方解くと、p・t など熱力学量の列は凍結流の値になり、
      isp・cf などは平衡流、ispfz・cffz などは凍結流の値になる（FCEA2 と同じ）。
      例は samples\plot_example.inp。
  (c) uv 問題は u/r を明示する必要がある:
        prob uv u/r=216.2102 rho,kg/m**3=1.799
      （反応物の温度から内部エネルギーを出す処理が v3 で未実装のため）
  (d) 凍結流（fr）の亜音速点（subar）だけ FCEA2 と値が違う
      （RP-1311 例題 8 で Isp が 0.45%）。スロートと超音速側は一致する。
  (e) データベースの "Paraffin" は FCEA2 では壊れていて使えなかったが、
      v3 では使える。ただし C73H124（H/C = 1.70）で、実際のパラフィンワックス
      （H/C ≒ 2.0）より水素が少ない。パラフィン系燃料は自分で組成と生成熱を
      与えること。
  (f) 液体 N2O（N2O(L)）はデータベースに無い。気体の "N2O" を使うと、
      タンクの液を噴射する場合は c*・Isp を 1〜2% 高く見積もる。液体として扱う
      なら組成とエンタルピーを指定する（samples\n2o_rp1.inp を参照）。
  (g) 有限断面積燃焼室（fac）の質量流束は単位なしで書く:  ma=1000
      （"ma,kg/s/m**2=1000" のように単位を付けると入力エラーになる）
  (h) 反応物表の見出しは KJ/MOL だが値は J/mol。|h| が大きいと "*****" に
      あふれる（表示だけの問題で、計算には影響しない）。


4. FCEA2 との照合結果
----------------------------------------------------------------------------
  同条件を FCEA2 と FCEA3LAB で解いた最大相対差（FCEA2 の出力桁で丸めた分）:

    N2O(L)/RP-1   Pc 10-50 bar, O/F 3-10, 平衡・凍結（42 解）   3.2e-5 以下
    LOX/RP-1      Pc 70 bar, O/F 2-3, 平衡・凍結（12 解）       2.3e-5 以下
    純 N2O の断熱分解（HP, 1-50 bar）                           3.9e-5 以下
    輸送物性（粘性・Cp・熱伝導率・Pr）                          1.5e-5 以下
    純 N2O の CJ デトネーション（1-50 bar）                     出力桁で一致
    RP-1311 例題 8（H2/O2, 平衡）                               1.2e-4 以下
    .plt（rocket 平衡・凍結・fac、tp・hp・uv、デトネーション）  1.4e-4 以下

  RP-1311 の全例題と上記ケースは、範囲検査付きビルドでもエラーなく通る。


5. 中身
----------------------------------------------------------------------------
  FCEA3LAB.exe       本体（単体で動く。追加のランタイムは不要）
  thermo.lib         熱力学データベース（v3.3.4 の thermo.inp から生成）
  trans.lib          輸送物性データベース
  data_src\          データベースの元データ（thermo.inp, trans.inp）
  samples\           入力例（RP-1311 例題、N2O(L)/RP-1、LOX/RP-1、N2O 分解、.plt）
  patches\           NASA CEA v3 に当てた修正の差分
  MODIFICATIONS.txt  修正の内容
  LICENSE.txt        Apache License 2.0（NASA CEA のライセンス）
  NOTICE.txt         NASA CEA の NOTICE
  BUILD_INFO.txt     ビルド条件

  起動を止められたとき（電子署名を入れていないため）:
  * Windows で「発行元不明」「PC を保護しました」と出たら、「詳細情報」→「実行」。
    または FCEA3LAB.exe のプロパティで「許可する」にチェックを入れる。
  * mac で「"FCEA3LAB" は開いていません」「開発元を確認できない」と出たら、
    次のどちらか。
      - ターミナルで、解凍したフォルダごとダウンロードの印を外す:
          xattr -dr com.apple.quarantine （解凍したフォルダをここへドラッグ）
      - 一度実行して警告を出したあと、「システム設定」→「プライバシーとセキュリティ」
        の下の方にある「このまま開く」を押して認証する（macOS 15 以降は右クリック
        →「開く」では通れない）。
    それでも "killed: 9" で終わるときは  codesign -s - -f FCEA3LAB  で簡易署名する。

  Windows・Linux・mac（Apple Silicon / Intel）の 4 種類があり、中身は共通。
